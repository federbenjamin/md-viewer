# MD Viewer

A very thin Markdown viewer for Safari on iPhone, iPad, and Mac. Not usable yet: this is the project skeleton.

## Install

Needs Xcode 27 and Node with pnpm.

```
pnpm install
cp Config/Local.xcconfig.example Config/Local.xcconfig
```

Put your own Apple team in `Config/Local.xcconfig`, then open the Xcode project.

## Test

```
pnpm test
```
